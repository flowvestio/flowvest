# Flowvest Roadmap

## V1 — Public Beta

- USDC only
- Fixed 3 periods
- No protocol fee
- Basic vesting

---

## V2 — Core Protocol

- Flexible duration (4–60 months)
- Protocol fee (0.5%)
- Beneficiary change
- Termination rules
- TVL cap

---

## V3 — Expansion

- Multi-token support (USDT, DAI)
- Multi-chain deployment
- Automation (keeper incentives)
- Advanced vest types

---

## Long-Term Vision

Flowvest aims to become a simple and reliable primitive for programmable payments.
